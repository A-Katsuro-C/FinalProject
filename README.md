# FinalProject

Welcome to the Resturant Ordering System:

You will be presented with 6 options;
1. Add to Order
2. Checkout
3. View All Transactions
4. Load Data
5. Save Data
6. Exit

Option 1, Adds a current order into the system using an ArrayList.

Option 2 uses a Recurisve Error Checking System that allows the user to pick which order is completed and gets move to an Array for past transactions.

Option 3 lets you see all current and past orders/transactions.

Option 4 Lets you load data, lets say for a pickup order from a file called orders.txt

Option 5 Lets you save data, possible for an order for another day

Option 6 Exits and terminates the program.
